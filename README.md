# Minifolio
A miniature-painting progress tracker. Free, works offline, and your data stays on your own device.

**Privacy:** no accounts, no cookies and no adverts, and your collection stays on your own device. The app counts visits anonymously with [GoatCounter](https://www.goatcounter.com): each time it opens from minifolio.app it asks for one tiny 1x1 picture (no cookies, no personal data, nothing from your collection is sent, and the security policy allows only that one address; if a link ends in a short tag such as `?from=club`, that one word is sent too, so visits can be counted by where the link was shared, and it is never saved). It can be switched off in Settings → Counting visits. Details are in Help → Privacy.
